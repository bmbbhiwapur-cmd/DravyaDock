# DravyaDock (द्रव्यDock)
### Computational Ayurvedic Molecular Docking Platform

DravyaDock bridges traditional Ayurvedic pharmacology (Dravyaguna Vidya) from the *Bhavaprakasha Nighantu* with modern translational structural bioinformatics and structure-based drug discovery pipelines.
